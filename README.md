# CodeAlpha_PhishingAwarenessTraining

A phishing awareness training presentation built as part of the **CodeAlpha Cyber Security Internship** (Task 2).

This project is an educational module designed to help everyday users recognize phishing attacks, understand the social engineering tactics behind them, and follow practical steps to stay protected.

## 📋 What This Project Covers

- **What phishing is** and why it's one of the leading causes of data breaches
- **Types of phishing**: Email phishing, spear phishing, vishing, smishing, clone phishing, and whaling
- **How to spot a phishing email**: sender mismatches, urgency, generic greetings, suspicious links, unexpected attachments, and requests for sensitive data
- **How to spot a fake website**: URL inspection, why HTTPS alone isn't proof of legitimacy, design red flags, and suspicious pop-ups
- **Social engineering tactics**: urgency, authority, fear, curiosity, and greed
- **Two fully annotated real-world style examples**: a fake account-alert email and a cloned login page, each broken down red flag by red flag
- **Best practices** for staying protected (MFA, password managers, verifying through separate channels, reporting suspicious messages)
- **An interactive-style quiz** to test understanding
- **Key takeaways summary** with references

## 🛠 Format

- **Deliverable:** PowerPoint presentation (`.pptx`)
- **Slides:** 11
- **Tools used:** Built and designed as a professional slide deck suitable for presenting to a non-technical audience (e.g., new employees during security onboarding)

## 🎯 Purpose / Audience

This presentation is designed to be used the way a company might use it during employee security onboarding — to teach non-technical users how to recognize and avoid phishing attempts without needing any prior cybersecurity background.

## 📚 What I Learned

- How phishing attacks are structured and why they remain one of the most effective attack vectors
- The psychological tactics (social engineering) attackers rely on rather than pure technical exploits
- Practical, actionable red flags that apply to both emails and websites
- How to communicate a technical security topic clearly to a non-technical audience

## ⚠️ Disclaimer

The email and website examples included in this presentation are **fictional mockups created for educational purposes only**. They do not represent real captured phishing attempts and are not affiliated with any real company.
